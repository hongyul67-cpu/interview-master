기관별 실제 기출 질문으로 모의 면접을 하고, 기업별 준비 카드와 채용 달력을 봅니다.

- 주소 : https://hongyul67-cpu.github.io/interview-master/

- 만든 날 : 2026-09-18

## 구성

| 탭 | 내용 |
|---|---|
| 📖 배우기 | 개념 카드 10개 — STAR, 만능 3종 세트(안전·갈등·개선), 상황면접 공식, 약점 방어, 전공 단답 |

## 고칠 곳

`index.html` 위쪽의 데이터 배열만 고치면 됩니다. 그 아래 코드는 대개 건드리지 않습니다.

| 배열 | 무엇 |
|---|---|
| `LEARN` | 배우기 카드 |
| `SETS` | 모의 면접 세트(기관)와 진행 방식 안내 |
| `QUESTIONS` | 질문 — `set` 세트 id · `q` 질문 · `follow` 꼬리질문 · `tip` 답변 전략 · `sec` 목표 시간 |
| `ORG` | 기업별 준비 카드 — `about` 어떤 곳인가 · `best` 가점에서 유리한 것(한 줄) · `job` · `exam` · `doc` · `itv` · `cert` · `tip` · `tipM` · `tipE` · `jaso` · `jasoT` · `pay` · `set` |
| `CERT` | 🏅 자격증 가점 비교 — 자격증별로 기관·배점을 모은 것. `ORG` 의 `cert` 에서 옮겨 적으므로 `cert` 를 고치면 여기도 함께 고칩니다 |
| `CAL` | 채용 달력 |

- `ORG` 의 필드는 비어 있어도 됩니다. 비어 있는 필드는 화면에 줄이 생기지 않습니다.
- `ORG` 에 `set` 을 적으면 그 기관 카드에 기출 질문 목록과 「이 기관 모의 면접 하기」 버튼이 붙습니다.
  없으면 ⭐ 기본 인성 세트로 안내합니다.
- 기업별 준비 탭에서는 **질문만** 보여 줍니다. 답변 전략(`tip`)은 모의 면접에서 답한 뒤에 공개됩니다.
- 데이터를 고친 뒤에는 반드시 문법 검사를 돌리세요(규약 5).
